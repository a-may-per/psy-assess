# 合规清单

> 状态：按双人简化模型重写（2026-10）。旧量表授权章节已删除（产品无量表，自研趣味内容）。产品定义见 [product-spec.md](product-spec.md)。

## 一、主体资质（最高优先级，第 1 周核实）

- [ ] **个人主体小程序**能否上线"测试/测评"类目（多数平台对测试类类目有限制或需企业主体）
- [ ] 若需企业主体：注册个体户/有限公司的成本与周期，对 3 个月死线的影响
- [ ] 流量主开通对主体类型的要求
- [ ] 小程序名称查重与商标风险（产品名未定）

## 二、内容红线（娱乐边界）

产品只做娱乐和自我了解，全链路文案遵循：

- 不出现诊断/筛查/疾病表述（完整禁用词表见 [content-pipeline.md](content-pipeline.md)）
- 不输出"谁有问题"的负面结论；角色两种都正面框架
- 拟人标签（"主人与小狗"类）逐个贬损感自审
- 免责声明：测评前告知 + 结果页固定位置（"仅供娱乐与自我了解，不构成任何专业建议"）
- AI 生成内容：模板化生成 + 人工终审；若上 AI 解读功能需过生成式 AI 合规（MVP 不做）

## 三、数据合规（个保法）

心理测评数据属**敏感个人信息**，双人配对额外意味着**系统关联两个用户的结果**：

- [ ] 隐私政策覆盖：敏感信息处理 + 配对关联关系 + 分享卡片会展示结果给对方
- [ ] 单独同意交互（测评前弹窗，不混在隐私政策里）
- [ ] 最小化：openid 匿名身份，不收集手机号/性别/年龄
- [ ] 未成年人：若大量学生参与配对，需评估监护人同意要求
- [ ] 删除权流程
- [ ] 数据留存期限与加密存储

## 四、平台合规

- [ ] 微信小程序类目资质（承接第一节）
- [ ] **诱导分享红线**：分享按钮/卡片只能自愿，解锁只挂激励视频，严禁"分享后解锁"
- [ ] 广告素材合规：激励视频/插屏不得出现医疗、夸大宣传类广告（开通后配置时检查）
- [ ] 测试结果夸大治理：文案不承诺"100% 准确"类表述

## 五、参考动作

1. 走查 1-2 个竞品的隐私政策、免责声明写法（截图存 docs/screenshots/）
2. 主体资质问题如不确定，咨询一次小程序开发者社区/平台客服（免费），暂不需要律师（无量表版权问题，旧文档的律师预算建议作废）
