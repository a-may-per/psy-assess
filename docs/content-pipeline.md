# 内容生产管线

> 进度：维度已确认、题库 v1 已出，见 [quiz-design.md](quiz-design.md)（2026-10-12）
>
> 状态：框架版（2026-10）。内容供给是本项目最大瓶颈（唯一可行路线已拍板，见下），本文件负责让它在第 1-2 周启动、与开发并行、不被开发吃掉工时。

## 供给路线（已拍板，单选）

**自研 + AI 辅助 + 人工精修。**

淘汰理由：
- 公版趣味题：不存在。公版资源都是单向量表，"独立答题+雷达图+关系画像+双方角色"这种内容无公版可抄
- 找专业合作：ARPU 0.1 元级、无预算无人脉、60 小时窗口，不现实

分工：
- **人工必做**：维度定义、题目计分骨架（选项→维度映射）、画像划分与角色分配规则、全部文案终审语气
- **AI 批量生成**：画像描述文案（模板化后）、金句候选、题目初稿
- **人工抽检**：AI 产出的语气、禁用词、贬损感

## 硬顺序（不可调换）

```
定维度（5 个）✅ → 定计分映射 ✅ → 写题（15 题，v1 已出）
→ 个人画像文案 → 画像库划分规则 + 角色分配规则 → 关系画像文案（6-8 个）
→ 文风终审 + 3-5 对真人试测
```

维度是数据模型的输入，必须第 1-2 周定死，否则开发返工。

## 工作量预算（计入 60h 总预算）

| 项 | 估算 |
|----|------|
| 15-20 题（含计分骨架，20-30 分钟/题） | 5-10h |
| 6-8 个关系画像文案（1-2h/个） | 7-16h |
| 个人画像文案（5 个） | 2-4h |
| 规则设计 + 文风终审 + 试测 | 3-5h |
| **合计** | **约 17-35h** |

若超支：砍题不砍维度（每维 3 题是底线）、画像砍到 6 个。首版上线后每周迭代 1 个新画像即可持续上新。

## 首版内容集（最小可上线版）

- 5 个维度 × 每维 3 题 = 每人 15 题（同一套题，所有人共用，保证分数可比）
- 6-8 个关系画像（各含：主画像文案 + 双方角色文案 + 分享金句）
- 5-6 个个人画像文案

## 文风规则（"有点准"的可执行定义）

1. **第二人称 + 具体行为场景**：不写"你是外向的人"，写"聚会里你往往是先开口的那个"
2. **先扬后轻分析**：先给正面框架，再用轻语气点相处特点；永不输出"谁有问题"
3. **禁用词表**（红线，全部文案适用）：
   - 诊断/疾病类：抑郁、焦虑症、人格障碍、心理疾病、治疗
   - 筛查类：检测出、患有、症状、筛查
   - 负面定性：有问题、不正常、糟糕、失败者
   - 贬损标签："主人与小狗"类拟人标签需逐个自审（弱方角色必须正面框架，如"治愈系小太阳"而非"小狗"？——写文案时定）
4. **金句标准**：一句话能截图；用户第一反应是"想发给对方"而不是"想删掉"

## 上线前检验

- 3-5 对真实朋友完整走流程
- 验收标准是**行为不是口头意愿**：TA 们把结果卡发进聊天了没有？
- 角色分配的公平感抽查：两种角色给两种人看，都不觉得被冒犯
