# 变现模型：流量主（广告）

> 状态：按双人简化模型重写（2026-10）。产品定义见 [product-spec.md](product-spec.md)。

## 模式一句话

个人结果永远免费（产品本体）→ 配对结果看激励视频解锁（核心变现点）+ 结果页 banner → 收入 = 广告曝光次数 × eCPM。

## 关键前提（先读）

1. **流量主开通门槛：累计独立访客 UV ≥ 1000**（以微信公众平台最新规则为准）
2. **流量主开通前，激励视频/banner/插屏等广告组件全部不可用**——广告 unit-id 只能在开通后创建
3. 因此：**3 个月目标期内产品实为全免费版**，唯一该优化的是 UV 增长；广告点位打磨是达标后的事
4. 达标后上解锁墙需过渡方案：已生成的配对结果不追溯，新配对才需解锁

## 解锁节点设计（已定，统一规则）

- **配对结果 = 激励视频解锁点**（谁看配对谁看广告）
- 个人结果（雷达图 + 个人画像）永远免费——墙不放在产品本体上
- 为什么墙放配对：个人结果是人人即得的完整体验，配对是增值层；A 的好奇心最重，愿意看视频
- 每对最多 2 次广告曝光（A、B 各一次）；统一规则实现最简，K 因子数据差再切"首次免费"（B 首看免费）
- 配对结果**不设**强制分享解锁（诱导分享红线）；分享卡片永远自愿
- 实现保持可配置：解锁墙开关独立，达标当天即可上线

## 广告位设计

| 位置 | 形式 | 设计 | 优先级 |
|------|------|------|--------|
| 配对结果解锁 | 激励视频 | 核心变现点，见上 | P0 |
| 个人/配对结果页底部 | banner/原生 | 常驻 | P0 |
| 完测返回/再测一次 | 插屏 | 自然停顿点 | P1 |
| 测评开始前 | 不放 | 保护完测率 | - |

## 单位经济（框架，达标后用真实数据替换）

假设激励视频 eCPM 50 元（经验区间 30-150，波动大）：

- 每对配对激励视频 1-2 次 → 约 0.05-0.1 元/对
- banner + 插屏 → 约 0.03-0.05 元/对
- 合计 ≈ **0.1 元/有效配对**（近似旧的"0.1 元/完测用户"，量级不变）

| 月有效配对数 | 月收入估算 |
|------------|-----------|
| 1,000 | ~100 元 |
| 10,000 | ~1,000 元 |

推论不变：单用户收入极低 → 不可买量；增长只能靠裂变 + 内容引流；规模是生死线。

## 增长飞轮

短视频/内容引流 + 朋友圈种子 → 进入测评 → 个人结果免费到手 → 生成邀请卡分享 → B 进入（个人结果同样免费）→ 配对结果好奇心 → 激励视频解锁 → 结果金句卡自愿分享 → 拉新循环

- K 因子 = 首次分享率 × 邀请点击率 × 第二人完成率；先积累基线，不预设数字
- 裂变断点保护：配对解锁墙放在 B 完成之后，不挡第二人完成率
