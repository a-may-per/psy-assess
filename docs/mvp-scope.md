# MVP 范围定义

> 状态：按双人简化模型重写（2026-10）。产品定义以 [product-spec.md](product-spec.md) 为准。

## 一句话目标

3 个月内累计独立访客 UV ≥ 1000，开通流量主。

> 注意口径：是**累计** UV（访客），不是日完测人数。双人测评每个有效配对天然带来 ~2 UV，≈500 对配对 + 内容自然流量即可达标。目标形状是「做好一个测评的裂变闭环」，不是「做大日活」。

## 核心假设（MVP 只为验证它）

趣味性格测评在微信生态里能靠分享裂变 + 短视频引流低成本积累 UV，且用户看到关系画像有足够好奇心看激励视频（广告解锁渗透率达标后才开启，属达标后验证项）。

## In Scope（MVP 必做）

- [ ] **内容集（最小可上线版）**：5 维度 × 每维 3 题 = 每人 15 题；个人画像文案；6-8 个关系画像 + 双方角色文案（见 content-pipeline.md）
- [ ] **测评主流程**：答题（盲测，不展示维度/目的）→ 个人雷达图 + 个人画像（全免费）
- [ ] **配对流程**：邀请分享卡（长期有效）→ B 进入 → B 已测过直接出配对 / 未测过先测后出配对 → 配对结果（主画像 + 双方角色 + 雷达图叠加）
- [ ] **分享卡片**：邀请卡 + 配对结果卡（自愿分享，严禁强制分享解锁）
- [ ] **基础账号**：openid 匿名身份、测评记录、复测
- [ ] **埋点**：见指标节
- [ ] **广告组件**：激励视频（配对解锁位）+ 结果页 banner —— **仅代码预留，流量主开通后才能生效**

## Out of Scope（明确不做）

- 任何付费功能（支付、会员）
- 双题库/两人不同题目（同题保证分数可比；双题库仅代码预留扩展位）
- 关系类型输入步骤（第一版不做"你们是情侣还是同事"选择，画像文案按未定项决策规避）
- 咨询/诊疗转介
- 社区、多语言、App
- 自研常模（趣味测评无需常模，此条替代旧文档的"竞品公开常模"方案）

## 里程碑（60 小时预算，内容与开发并行）

| 周 | 内容线（每周约 2h） | 开发线（每周约 2-3h） |
|----|-------------------|---------------------|
| 1-2 | ~~定维度+计分~~ ✅ 已完成（quiz-design.md v2），转入写题 | 小程序骨架、openid、数据模型 |
| 3-4 | 精修 15 题（v1 已出）+ 个人画像文案 | 答题流程、雷达图渲染、个人结果页 |
| 5-6 | 6-8 个关系画像 + 角色分配规则 + 文案 | 配对逻辑、邀请卡、分享卡片 |
| 7-8 | 文风终审 + 3-5 对真人试测 | 埋点、审核提审、上线 |
| 9-12 | 短视频 1-2 条/周 + 数据观察 | 修复 + 迭代 |

## 北极星与关键指标

**北极星：有效配对完成数**（两人都完成并生成关系画像的配对次数）
**关键早期指标：首次分享率**（#2：第二人完成率）

| 环节 | 指标 | 定义 |
|------|------|------|
| 获取 | 新增 UV | 累计 UV 是流量主门槛的直接分子 |
| 激活 | 测评开始率 / 完成率 | 进入 → 开始 → 完成 |
| 增长 | 首次分享率 | 完测 → 生成邀请卡并分享 |
| 增长 | 邀请点击率 / 第二人完成率 | 卡片曝光 → 进入 → 完成 |
| 北极星 | 有效配对完成数 | 两人完成 → 生成关系画像 |
| 增长 | 结果分享率 | 看到配对结果 → 再次分享 |
| 变现（开通后） | 解锁渗透率 / 人均广告次数 | 配对结果页 → 看激励视频 |

### 埋点事件

```
test_start, test_complete, personal_result_view,
invite_card_generate, invite_card_share, invite_link_click,
partner_entry (区分新用户/已测用户), partner_test_start, partner_test_complete,
pair_result_generated, pair_result_view,
reward_ad_show, reward_ad_complete, pair_result_share,
pair_abandon (B 未完成配对的配对数)
```

统计工具：先用微信小程序自带统计 + 自建事件表（云开发数据库聚合），够用再考虑第三方。

## 风险

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 内容生产拖慢上线 | 高 | 高 | 内容线第 1 周启动，与开发并行；最小集先行（content-pipeline.md） |
| 首次分享率低，裂变起不来 | 中 | 高 | 分享金句质量即增长引擎（文风规则 + 真人试测）；失败则靠短视频内容引流兜底 |
| 个人主体无法上测试类目 | 未知 | 高 | 第 1 周核实（compliance.md），必要时注册个体户/企业主体 |
| 同事/朋友配对出"伴侣"画像 | 中 | 中 | 画像标签决策未定项必须先关闭（product-spec.md） |
| 结果"不准"或角色分配引反感 | 中 | 中 | 每维 ≥3 题、确定性角色分配规则、拟人标签礼仪自审 |
| 达标后解锁墙上线伤体验 | 低 | 中 | 预留过渡方案：老用户已生成的配对结果不追溯 |
