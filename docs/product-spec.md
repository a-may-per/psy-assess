# 产品规格（唯一权威定义）

> 状态：已与用户逐项确认（2026-10 交互式梳理）。其他文档与本文件冲突时，以本文件为准。

## 一句话

任何人都可独立完成的趣味性格测评（个人雷达图），测完可邀请另一人也测，两个独立结果自动配对出一份趣味关系画像。个人结果永远免费，配对结果看激励视频解锁。

## 核心模型：单人测评是本体，配对是增值层

```
任何人 → 独立做测评 → 个人结果（雷达图 + 个人画像）   ← 核心产品，人人即得，永远免费
                ↓
        想配对 → 邀请对方做同一个测评（对方同样得到完整个人结果）
                ↓
        两个独立结果自动生成 → 关系画像（+ 双方角色）  ← 增值层，激励视频解锁
```

- 不存在"A 做完干等 B"的依赖流程；A 拿到个人结果即完成完整体验
- **答题盲测约束：答题过程中不得展示测量维度、计分目的、算法意图或"正在测·xxx"标签；用户只看到中性的题号、进度和答题提示。维度只在结果页出现。**
- **打散约束（2026-10-19）：题目顺序和答案计分位置都必须打散，选项的高分位（4 分）在 A/B/C/D 上尽可能平均分布。打散必须是固定打乱（所有人看到同一套顺序），不允许每次加载随机——保证两人同题比分的前提。题目按维度轮转交错排列，禁止同维度三题连排（连排会暴露维度，破坏盲测）。**
- B 通过邀请进入：
  - B 未测过 → 正常做测评（先看到自己的个人结果），完成后解锁与 A 的配对结果
  - B 已测过 → 系统按 openid 识别，跳过答题，直接看广告解锁配对结果
- 同一套题库给所有人（保证 0-100 维度分跨人可比；双题库仅为代码预留的扩展位，不是 MVP 事项）

## 已确认决策清单

| 项 | 决策 |
|---|---|
| 平台 | 微信小程序（个人主体 vs 企业主体待核实，见 compliance.md） |
| 变现 | 流量主（广告）；个人结果永远免费；配对结果 = 激励视频解锁（统一规则：谁看配对谁看广告，先做统一版，K 因子数据差再考虑"首次免费"） |
| 3 个月硬目标 | 累计独立访客 UV ≥ 1000 → 开通流量主（约需 ~500 对配对 + 内容自然流量） |
| 北极星 | 有效配对完成数（两人都完成并生成关系画像的配对次数） |
| 关键早期指标 | 首次分享率（#2：第二人完成率） |
| 维度 | 固定 5 个：主导/照顾/外放/计划/情绪（每维 3 题；「独处电量」已并入「外放度」，2026-10-12 确认，明细见 quiz-design.md） |
| 题目 | 每人同一套 15 题，无互动题；计分映射已定死（quiz-design.md） |
| 个人结果 | 雷达图（顶点数 = 维度数，每点 0-100 个人特征分）+ 个人画像 |
| 配对结果 | 单一主画像 + 双方角色；不显示契合度数字；雷达图同维叠加展示 |
| 画像库 | 6-8 个固定画像（MVP 最小集），现实关系词与拟人化标签是否混用待定（见未定项） |
| 匹配规则 | 独立规则（雷达图只展示）+ 组合规则（特征映射 / 角色互补 / 相处模式）；始终有结果，差异大也输出有趣画像 |
| 文案语气 | 趣味分析（有趣但"有点准"）；允许轻度相处分析；禁止负面判断与诊断表述 |
| 隐私 | 第二人完成 → 看到配对结果 → 分享回第一人；不展示双方具体题目答案 |
| 邀请卡 | 分享卡片形式，长期有效 |
| 引流 | 短视频，不露脸内容，低频持续（1-2 条/周），平台未定（见 growth 待核实） |

## 未定项（有意推迟，非遗漏）

- 画像库现实关系标签（伴侣/挚友）vs 纯动力学比喻 —— 写画像文案前必须二选一
- 拟人标签礼仪红线（"主人与小狗"类）—— 写文案前自审
- 短视频平台选择 —— 发第一条视频前核实各平台小程序导流规则

## 边界（娱乐边界）

只做娱乐和自我了解：不用"筛查/诊断"表述，不输出"谁有问题"的结论，不碰心理疾病判断。
