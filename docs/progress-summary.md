# 项目交互进展汇总

> 汇总时间：2026-10-31  
> 本文用于记录从前期方向讨论到当前方案的演进、已完成成果和待办事项。若本文与产品细节文档冲突，以 [product-spec.md](product-spec.md) 为准。

## 一、当前结论

产品已从早期的「轻心理测评矩阵」收敛为一款 **C 端微信小程序**：

> 用户独立完成 15 题趣味性格测评，免费获得五维雷达图和个人画像；测完后可邀请另一人完成同一套题，两份结果自动生成趣味关系画像。个人结果永远免费，配对结果在流量主开通后通过激励视频解锁。

当前不做专业诊断、心理咨询、付费报告、会员、独立 App，也不把算命、解梦或脑力训练作为核心产品。

## 二、交互与决策演进

### 1. 2026-08-24：确定轻心理方向（ASTE-6）

- 初步调研梦境、人格、关系和情绪类测评产品。
- 判断不适合直接做纯算命、纯解梦或专业咨询平台。
- 建议以微信小程序/H5 验证，用热点题材吸引点击，以关系、情绪和人格内容承接。
- 形成「比玄学更可信、比专业咨询更轻松、比普通 MBTI 更适合分享」的早期定位。

### 2. 2026-08-26：形成品牌与内容矩阵设想（ASTE-9）

- 早期总品牌首选名为「心灵天气」，备选包括「心灵地图」「心灵图鉴」。
- 梳理了热点角色、梦境、每日情绪、关系互动、标准人格、趣味轻测等内容线。
- 这阶段的多测评矩阵是探索方案，**不是当前 MVP 范围**；产品名也尚未最终确认。

### 3. 2026-08-26 至 08-31：猫系角色测评原型（ASTE-8）

- 确认角色型、猫系人格适合作为热点切口，但未经授权不应直接绑定具体 IP。
- 产出过一版 15 题、4 类结果的题库和低保真设计稿。
- 根据反馈，将通用 App 式页面调整为微信小程序式结构：顶部导航、单列卡片、底部固定 CTA。
- 该探索验证了「15 题速测 + 结果画像 + 分享海报」的表达方式；当前方案已改为原创五维测评，旧四类型计分不再作为正式口径。

### 4. 2026-08-27：脑力 PK 与协作玩法评估（ASTE-10）

- 结论是适合融入，但应定位为轻量游戏化和关系互动，不宣称提升智商或治疗注意力。
- 玩法顺序建议：双人异步 PK → 双人协作 → 多人协作/实时房间。
- 当前决定：**不进入 MVP**。未来可作为分享拉新、每日留存或关系互动的 P1/P2 扩展。

### 5. 2026-10：产品主线完成收敛

- 单人测评成为完整、免费、可独立成立的核心体验。
- 双人配对成为增值层，而不是强依赖流程。
- 变现统一为流量主广告，不做支付和会员。
- 固定五个维度：主导、照顾、外放、计划、情绪。
- 固定 15 题、每维 3 题、同一套题跨用户可比。
- 答题过程盲测；题目维度交错，答案计分位置固定打散。
- 配对结果采用「单一主画像 + 双方角色 + 雷达图叠加」，不显示契合度数字，不评判谁更好。
- 三个月目标明确为累计 UV ≥ 1000，以有效配对完成数为北极星指标。

## 四、当前小程序实现状态（2026-10-31 进化版）

`demo/` 已从最初的单文件静态演示进化为结构化的 MVP 小程序实现：

已具备：

- **跨端高清雷达图组件**（[RadarChart.tsx](file:///Users/fdf/Github/psy-assess/demo/src/components/RadarChart.tsx)）：修复原内联 `<svg>` 在微信小程序 WXML 下无法渲染的问题，采用 Data URI 矢量渲染，支持单人五维图与双人同维叠加图。
- **15 题盲测与精修题库**（[quizData.ts](file:///Users/fdf/Github/psy-assess/demo/src/data/quizData.ts)）：5 维度 3 轮交错排列、固定排列矩阵 `PERMS` 打散选项、全程盲测不暴露维度。
- **完整个人画像与 8 大关系画像引擎**（[matchingEngine.ts](file:///Users/fdf/Github/psy-assess/demo/src/data/matchingEngine.ts)）：
  - 个人画像：5 主维度原型 +「收放自如的平衡漫游者」+「自在松弛的随风漫游者」兜底，含五维正反极性标签与场景化拆解。
  - 关系画像：采用纯动力学比喻（如「掌舵与定心丸」「蓝图与奇遇记」「同频共振拍档」「灵感造浪搭子」「静音充电同盟」「温室守护同盟」「双核推进拍档」「引力平衡搭子」），朋友/伴侣/同事通用，不打契合度分数。
- **真实 A→B 邀请配对闭环与存储层**（[storage.ts](file:///Users/fdf/Github/psy-assess/demo/src/services/storage.ts)）：
  - 支持微信原生转发卡片参数携带（`?inviteId=...&fromScores=...`），跨设备无需重后端也能直接合并生成同一份关系画像。
  - 完整覆盖 B 进入的两条分支：**B 已测过（按 openid 识别免答题直出配对）** 与 **B 未测过（先得免费个人结果，再揭晓配对结果）**。
  - 内置「发起人 A / 受邀好友 B」一键视角切换与 4 位示例搭子试配。
- **流量主激励视频与合规、埋点闭环**（[analytics.ts](file:///Users/fdf/Github/psy-assess/demo/src/services/analytics.ts)、[index.tsx](file:///Users/fdf/Github/psy-assess/demo/src/pages/index/index.tsx)）：
  - 流量主模式开关（UV < 1000 全免费期 vs 开通后新配对激励视频解锁，历史已生成配对自动豁免不追溯）。
  - 测评前敏感个人信息单独知情同意弹窗、免责声明、一键删除全部个人记录入口。
  - 15 个核心埋点事件与实时漏斗看板（完测率、首次分享率、B 完成率、北极星有效配对数）。

## 五、当前最高优先级

### P0｜上线前必须关闭

1. **主体与类目核实**：确认个人主体能否上线测试/测评类小程序，以及流量主主体要求。
2. **精修 15 题**：检查单题区分度、选项递进、语气一致性和答案计分打散。
3. **补齐结果内容**：完成个人画像、6-8 个关系画像、双方角色和分享金句。
4. **关闭画像标签决策**：确定现实关系词与纯动力学比喻是否混用，排除有贬损感的拟人标签。
5. **实现真实配对闭环**：openid、数据模型、邀请关系、第二人状态、结果生成和历史查看。
6. **补齐合规流程**：隐私政策、敏感信息单独同意、删除入口、免责声明和自愿分享。

### P1｜闭环可运行后

1. 完成 3-5 对真实朋友试测，观察是否真实分享，而不是只询问意愿。
2. 完成埋点和漏斗看板，重点观察完测率、首次分享率、邀请点击率、第二人完成率。
3. 做 3-5 个竞品的完整流程走查，重点记录题量、结果页、配对玩法、分享路径和广告位置。
4. 开始每周 1-2 条不露脸短视频，验证内容引流。

### P2｜有数据后再评估

- 双人 PK、双人协作、多人协作和每日小游戏
- 更多热点皮肤或原创角色宇宙
- 今日心理天气等签到留存模块
- AI 个性化解读、社区、App、专业服务

## 六、建议下一步

下一阶段不再继续扩充概念，直接执行两条并行线：

1. **内容线**：精修题库 → 个人画像 → 关系画像与角色规则 → 真人试测。
2. **开发线**：将现有 Demo 拆为正式页面 → 接入 openid 与数据层 → 跑通邀请配对 → 接入埋点与合规交互。

首个可验收节点应是：两位真实用户分别完成同一套测评，均获得个人结果，并能通过真实邀请关系生成同一份配对画像。
