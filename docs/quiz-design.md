## 维度设计原则

- 全部是日常可观察的行为（"有点准"的前提是用户能对上号）
- 高低两端都正面框架（高不更好，低不更差）
- 与关系类型解耦（同事/朋友/情侣/家人都适用）——"关系感"由配对层产生，不出现在题目里
- 2 个极性轴支撑角色分配，其余支撑相处模式与特征映射

## 五个维度（已确认）

| # | 维度 | 高分端（100） | 低分端（0） | 雷达图标签 | 在配对中的作用 |
|---|------|--------------|------------|-----------|---------------|
| 1 | 主导度 | 拍板型：习惯拿主意 | 随和型：都行，跟着走 | 主导 | 角色分配主轴①（谁说了算） |
| 2 | 照顾度 | 操心型：忍不住照顾人 | 放养型：相信你能搞定 | 照顾 | 角色分配主轴②（谁照顾谁） |
| 3 | 外放度 | 人群充电：人来劲，有话直说 | 独处回血：安静内敛，自己消化 | 外放 | 相处模式（热闹搭子 vs 安静陪伴） |
| 4 | 计划度 | 行程表型：万事提前安排 | 随缘型：说走就走 | 计划 | 相处模式（规划 vs 惊喜） |
| 5 | 情绪浓度 | 细腻型：感受深，上头快 | 大条型：心大，翻篇快 | 情绪 | 特征映射（原型素材） |

## 计分映射（已定死）

- 每题 4 个选项，计 4/3/2/1 分，**强迫选择不设中间项**
- 每维 3 题：维度原始分 = 3 题均分（1-4）
- 线性映射：`(均分 - 1) / 3 × 100`，四舍五入取整，粒度 10 档（0, 11, 22, …, 100）
- 无反向题：选项直接计分

## 出题顺序（打散约束，2026-10-19）

- 题目按维度**轮转交错**展示（主导→照顾→外放→计划→情绪→主导→…），禁止同维度连排暴露盲测
- 答案计分位置用 15 组固定排列打乱，4 分位在 A/B/C/D 上均衡（4/4/4/3）
- 打散是**固定**的：所有人同一套顺序，这是跨人比分（product-spec 同一套题库决策）的前提，不允许每次加载随机

## 题库 v1（15 题，待精修）

> 规则：每题同一场景下递进程度的具体行为，选最像自己的；场景不重复；不出现"男/女朋友/对象"等关系类型字样。

**Q1. 群里约饭选店，你一般……**（主导）
- A 直接甩三个链接让大家投票（4）
- B 主动说想去哪家，别人有意见再改（3）
- C 等大家提，谁提得具体就跟谁（2）
- D 都行，你们定就好（1）

**Q2. 出去玩要做攻略，你通常是……**（主导）
- A 我来做全套攻略，你们跟着玩（4）
- B 我订关键的大头，其他随机（3）
- C 有人做就跟着，没人做再管（2）
- D 反正有人会安排，我不操心（1）

**Q3. 大家商量一件事僵住了，你会……**（主导）
- A 拍板："就选这个，错了我担着"（4）
- B 帮忙理出两条路，推动做个决定（3）
- C 继续听，等有人先表态（2）
- D 僵着就先放放，聊点别的（1）

**Q4. 朋友说感冒了躺着，你会……**（照顾）
- A 直接点好粥和药送过去（4）
- B 反复叮嘱多喝水，过两小时问一次（3）
- C 关心一句"好好休息"（2）
- D 回个表情包，等 TA 好了再说（1）

**Q5. 朋友情绪很低，连续几天没什么动静，你会……**（照顾）
- A 直接上门或打电话，人到了再说（4）
- B 发长消息认真问，陪 TA 聊到好一点（3）
- C 发条消息让 TA 知道你在（2）
- D 觉得 TA 需要空间，等 TA 来找（1）

**Q6. 出门突然下雨，同行的人没带伞，你会……**（照顾）
- A 把伞整个偏过去，自己半边湿（4）
- B 凑一把伞，商量路线怎么走（3）

- D 先快走几步，在前面等（1）

**Q7. 一场热闹的聚会结束，回家路上你……**（外放）
- A 还很兴奋，想接着组下一场（4）
- B 挺开心，到家还想找人聊两句（3）
- C 刚好，安安静静待一会儿（2）
- D 累了，谁也别找我，回血中（1）

**Q8. 心里憋着事的时候，你会……**（外放）
- A 找人说出来，说着说着就好一半（4）
- B 找靠谱的人聊聊，但只挑重点（3）
- C 自己待一会儿，慢慢消化（2）
- D 绝口不提，过两天自己就忘了（1）

**Q9. 在一个热闹的群里，你通常是……**（外放）
- A 气氛担当，一开口大家就接（4）
- B 偶尔冒泡，说到点上会聊几句（3）
- C 潜水为主，精彩处点个赞（2）
- D 几乎隐身，只看不说（1）

**Q10. 周五有人约你周末出去玩，你的反应是……**（计划）

- B 大方向先说好，细节到时候看（3）

**Q11. 到一个陌生城市或商场，你的习惯是……**（计划）
- A 出发前路线全排好，照着走（4）

**Q12. 说好的安排突然被临时取消，你会……**（计划）

**Q13. 朋友回消息语气好像有点冲，你会……**（情绪）

**Q14. 看到影视剧里感人的情节，你通常……**（情绪）

- D 全程无感，顺手刷手机（1）

**Q15. 有人当面直接指出你的问题，你会……**（情绪）
- A 当场就有情绪，需要缓很久（4）
- B 嘴上说没事，心里嘀咕好几天（3）
- C 有点不舒服，睡一觉就没事了（2）
